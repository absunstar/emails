# My Emails Priority UI Release

- Fixed saved inbox selection incorrectly showing the `Address removed` toast.
- Selecting a saved inbox now only switches the inbox; removal remains an explicit trash-button action.
- Promoted the saved inbox list into a visually distinct primary `Saved inboxes` panel.
- Search and sort stay above the saved inbox list.
- Notifications and Sound moved into a secondary tools area at the bottom of the sidebar.
- Export and Import are now direct bottom actions.
- Backup & Restore Manage remains available as a secondary detailed workflow.
- Active inbox styling and saved-inbox panel contrast were strengthened.
- Full-width homepage, Admin, Abuse Policy, 10k scaling and 34-tool Manager MCP are preserved.
